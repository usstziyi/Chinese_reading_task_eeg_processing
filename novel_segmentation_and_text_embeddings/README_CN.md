# 中文语料切分与文本嵌入

## 简介

本 README 旨在说明如何使用预训练语言模型对中文小说进行句子切分并获取文本嵌入。

## 环境

我们使用 `xlsx` 文件保存切分后的小说。我们使用 `openpyxl` 包将内容写入 Excel 文件。你可以用 pip 安装该包：

```
pip install openpyxl
```

此外，我们还需要用于深度学习和预训练语言模型的包，因此需要安装 PyTorch 和 Transformers。

```
pip install pytorch
```

```
pip install transformers
```

## 说明

### 小说切分

运行 `cut_Chinese_novel.py` 处理 `.txt` 格式的中文小说以进行句子切分，得到相应的 `.xlsx` 格式文件。

`cut_Chinese_novel.py` 用于将小说处理成适合在 PsychoPy 程序中呈现的格式。小说内容会被切分为一系列单元，每个单元不超过 10 个汉字，相邻的三个单元组合成屏幕呈现时每一帧的内容。同一组相邻单元会重复多次，以便后续对每个单字进行高亮显示。此外，你可以指定从某些章节起将小说切分为多个部分，并分别输出为独立的文件。

该脚本的输入必须是 `.txt` 格式的中文小说内容。小说内容的格式需满足以下要求：

1. **文件开头应包含以** **`Ch0`** **标记的前言部分**。前言将作为正式章节阅读前的模拟（练习）。
2. 后续每个章节应以 **`Ch + <章节号>`** 标记开头。

示例如下（文件名为 `Chinese_novel.txt`）：

```
Ch0
This is the preface of the novel
Ch1
Chapter 1 of the novel
Ch2
Chapter 2 of the novel
...
...
...
```

在实际实验中，考虑到眼动仪电池续航等问题，我们必须在实验过程中更换电池。由于技术限制，更换电池时我们不得不暂时停止实验程序。因此，我们可能会把一整本小说切分为多个部分，在每次完整的程序运行中呈现其中一个部分。例如，我们可能把一本 30 章的小说切分为 4 个部分，并多次运行程序以完成整本小说的内容。

在该脚本中，你可以通过修改参数 `divide_num` 指定要对小说进行切分的章节，程序将按这些章节切分并输出包含这些不同部分的文件。

输出有三种类型的数据文件：

- 第一种文件包含小说的完整内容，其内容按屏幕显示时的每一行切分。该文件命名为 `segmented_Chinese_novel.xlsx`。在这类数据中，**我们去掉了所有不含汉字的行，即那些完全由标点符号组成的行**。原因如下：在实际显示过程中，只包含标点的行不会显示在屏幕中央供被试阅读。因此，在与 EEG 数据相关的分析中，这些行没有对应的数据分段。
- 第二种文件包含每次试次（即某一次会话中播放的指定章节）的内容，同样按显示时的每一行切分，这些文件命名为 `segmented_Chinese_novel_run_xx.xlsx`，其中 `xx` 为具体的 run 编号。**出于上述相同的原因，我们也去掉了所有不含汉字的行。**
- 第三种文件是专门用于在屏幕上投影内容的文件。它与第二种文件直接对应，其中每个文件都是第二种文件的变换。这些文件的主要目的是通过 PsychoPy 程序在屏幕上呈现内容，因此我们在第二种文件的文件名末尾加上 "display" 以示区分。格式为 `segmented_Chinese_novel_run_xx_display.xlsx`。

我们提供了小说《小王子》的 `.txt` 文件以及处理后的 `.xlsx` 文件作为示例。

#### 参数

| 参数                   | 类型  | 用途                                                                  |
| -------------------- | --- | ------------------------------------------------------------------- |
| divide\_nums         | str | 要将小说切分的断点（逗号分隔）。例如，如果想从第 8、16、24 章处切分，应传入参数 `--divide_nums=8,16,24` |
| Chinese\_novel\_path | str | 你的 `.txt` 格式中文小说内容的路径                                               |
| save\_path           | str | 输出文件的保存路径                                                           |

#### 运行

可以使用以下命令运行该代码：

```
python cut_Chinese_novel.py --divide_nums=<chapter numbers of the cutting point> --Chinese_novel_path=<path to your .txt file of the novel> --save_path=<path to save the outputs>
```

### 文本嵌入

我们提供 `embedding.py` 用于生成文本嵌入。我们采用基于深度学习的预训练语言模型来计算文本嵌入。我们使用的预训练模型是 [bert-base-chinese](https://huggingface.co/bert-base-chinese)。具体来说，我们处理文本刺激中的每一行文本，生成统一长度的文本嵌入。这些嵌入按实验中的每个 run 进行组织，并以 `.npy` 格式保存。因此，每个文本嵌入的 `.npy` 文件对应一次 run 中每行文本刺激的嵌入。你应该传入所有 run 的 `.xlsx` 格式文本文件路径作为输入（即上文小说切分部分的输出路径）。

我们已经计算了两本所用小说的嵌入。它们可以在数据集的 `derivatives/text_embeddings` 目录中获取。你可以直接使用它们进行后续分析，包括 EEG 与文本在表征空间中的对齐以及 EEG 语义解码。**注意：由于实验过程中的特殊情况，LangWangMeng 会话中的被试 07 在第 18 次 run 中未按原定计划阅读第 18 章的内容，而是改读了第 19 章的内容作为替代。因此，在该特定情况下，第 18 次 run 的 EEG 数据与第 18 个文本嵌入文件之间没有直接对应关系。**

#### 运行

| 参数                   | 类型  | 用途                      |
| -------------------- | --- | ----------------------- |
| Chinese\_novel\_path | str | 包含每次 run 文本刺激的文件夹路径     |
| run\_num             | int | 实验中 run 的次数（即文本刺激文件的数量） |
| save\_path           | str | 保存嵌入文件的路径               |
